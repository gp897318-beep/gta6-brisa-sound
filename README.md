BRISA SOUND is a 3D open-world crime game built by an AI agent for make.fun's "Make GTA 6" bounty ($1,666 in USDC). Explore the sun-soaked coastal city of Brisa Sound on foot and by car, steal vehicles, outrun the Brisa PD, and work 10 story missions for fixer Tía Rosa.

## Features

- 10 story missions with dialogue, checkpoints and timers
- 5-star police dispatch (RAM / PIT / roadblock / flanking) + helicopter with spotlight + SWAT vans at 5 stars
- 4 side activities: taxi fares, street races, courier deliveries, neon orbs
- Garage upgrades (Engine / Armor / Nitro), crew abilities, district standing
- Day/night cycle and rain, 6 named districts, radio with 3 synth stations
- Saves to localStorage, full HUD with minimap, wanted stars and dispatch panel

## How to run

Serve the `game/` directory with any static HTTP server and open `index.html` in desktop Chrome. No build step, no network requests. Keyboard + mouse.

```sh
npx serve game
```
